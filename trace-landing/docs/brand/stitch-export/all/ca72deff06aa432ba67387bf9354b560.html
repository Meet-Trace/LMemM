Common Inquiries

Frequently asked questions

Does Trace record everything on my screen?

expand_more

No. Trace does not indiscriminately capture screenshots or raw video footage. Instead, it extracts structured semantic metadata from supported applications and deliberate user saves, keeping processing lightweight, non-invasive, and completely transparent.

Where is my project memory stored?

expand_more

Your retained memory is stored locally on your Mac using encrypted embedded storage. It never leaves your machine unless you explicitly choose to export or pipe a bundle into an external tool.

Can I use Trace with my existing notes and tools?

expand_more

Yes. Trace connects seamlessly with Apple Notes, Safari, Chrome, Slack, Notion, and standard local markdown files, acting as a unified bridge between your fragmented work surfaces.

When is Windows and Linux support coming?

expand_more

We are laser-focused on perfecting the macOS experience first to leverage Apple Silicon neural accelerators. Windows and Linux builds will follow as we scale beyond early access.

Frequently Asked Questions

Does Trace remember everything on my computer?

No. Trace works with supported sources and the permissions you choose. Some content, including browser evidence, needs an explicit save.

Do I need to use AI?

No. Trace also helps you return to saved project context yourself.

Can my team use it together?

Shared team memory is part of our vision. Early access starts with the individual Mac experience.
